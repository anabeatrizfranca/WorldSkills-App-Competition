# Sobre o Projeto | About the Project

### 🇧🇷 Português

Este projeto foi desenvolvido em 2024, durante minha participação na competição **WorldSkills**, utilizando **Kotlin** como linguagem de programação e **Android Studio** como ambiente de desenvolvimento.

Recentemente, consegui recuperar os arquivos desses projetos, que estavam armazenados em uma antiga conta do GitHub à qual havia perdido o acesso. Por isso, estou republicando-os neste perfil para preservar e compartilhar parte da minha trajetória acadêmica e profissional na área de tecnologia.

Na época, utilizava o **Android Studio** para desenvolver aplicações Android. Atualmente, utilizo principalmente o **Visual Studio Code (VS Code)** em meus projetos e estudos.

Este repositório representa uma parte importante da minha jornada de aprendizado, dos desafios que enfrentei e das habilidades que desenvolvi durante minha experiência na WorldSkills.

---

### 🇺🇸 English

This project was developed in 2024 during my participation in the **WorldSkills** competition, using **Kotlin** as the programming language and **Android Studio** as the development environment.

I recently managed to recover these project files, which were stored in an old GitHub account that I had lost access to. I am now republishing them on my current profile to preserve and share part of my academic and professional journey in technology.

At the time, I used **Android Studio** to develop Android applications. Currently, I mainly use **Visual Studio Code (VS Code)** for my projects and studies.

This repository represents an important part of my learning journey, the challenges I faced, and the skills I developed during my WorldSkills experience.
